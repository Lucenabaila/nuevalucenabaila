# Lucena Baila — Nueva Web

Primera versión de la nueva web de Lucena Baila.

## Tecnología
- Next.js
- React
- CSS propio responsive

## Desarrollo
```bash
npm install
npm run dev
```

## Producción
```bash
npm run build
npm run start
```

Esta versión es una base visual. Las fotos reales, horarios reales, contenido editable, base de datos y panel de administración se añadirán en las siguientes fases.
